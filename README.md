# 自然选择号｜六推进版公开展示

《我的三体》主题的非官方战舰建模与拆解动画作品。[交互展示页](https://zzr061229-creator.github.io/natural-selection-showcase/)提供可旋转、可缩放的静态展示模型，并附效果图和 32 秒拆解视频。

公开内容只包含轻量化静态 GLB、渲染图、视频和展示网页。网页必须向浏览器传输 GLB，因此访问者可以取得展示模型；建模脚本、Blender 工程、源贴图、高精度资产及完整拆解工程始终保留在独立的私有仓库。网页前端代码可见，但不包含建模方法或工程源文件。

六推进舱布局属于本作品的创作补全，并非官方结构确认。本仓库不附开源许可证。原作名称、设定及标识的权利归原权利人所有。
